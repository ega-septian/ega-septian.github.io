## Preview locally

```bash
python3 -m http.server 8123
```

Open http://localhost:8123/.

## Notes

- The CV PDF sits in the repository root and is linked from the page.
- The portrait and social preview image are in `assets/`.
- Pushing to `main` deploys the site through GitHub Pages.

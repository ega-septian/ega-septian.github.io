Redline

Root-cause analysis for Playwright failures.

When a test fails, the real question is whether the bug is in the app, the test, or the environment. Redline answers it automatically — grouping failures across runs, checking them against deterministic rules and the OpenAPI contract, then using Claude only when the evidence is ambiguous.

  • Groups failures by root cause — backend bug, test bug, environment, or flaky — across runs.
  • Combines rules and contract validation with LLM analysis, redacting JWTs, passwords, and tokens first.
  • Proves causes by rerunning tests with AI-generated patches: 92–100% accuracy and zero false positives on a planted-bug benchmark.
  • Go
  • TypeScript

Test architecture 2026

Three-Agent QA Pipeline

Spec-driven QA, from requirement to Jira closure.

A test architecture for an e-commerce app that separates product intent, test design, and automation across three independent agents. Expected results are written from the spec, never copied from the code they are meant to verify.

  • Product Manager, QA Tester, and Automation Engineer agents work from separate sources of truth.
  • GitHub Actions runs the full Playwright API and web suite on every push.
  • A passing merge automatically closes the Jira ticket it was written for, with no manual status updates.
